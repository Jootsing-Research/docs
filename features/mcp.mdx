The TapKit MCP server connects Claude to a physical iPhone — letting Claude see the screen, tap, swipe, type, and navigate apps using visual coordinates. No accessibility tree, no DOM, no jailbreak required.

The MCP server runs as a hosted endpoint. You don't need to run anything locally beyond the [TapKit Mac app](/setup/mac-app) with a connected iPhone.

## Tools

Call `list_phones` first to discover available phones. Every other tool requires a `phone_id` returned by `list_phones`.

| Tool | Description |
|------|-------------|
| `list_phones` | List available phones |
| `screenshot(phone_id)` | Capture the current phone screen as an image |
| `tap(phone_id, x, y)` | Single tap at coordinates |
| `type_text(phone_id, text)` | Type text into the focused field |
| `press_home(phone_id)` | Go to the home screen |
| `swipe(phone_id, x, y, direction)` | Swipe up, down, left, or right |
| `drag(phone_id, from_x, from_y, to_x, to_y)` | Drag between two points |
| `hold_and_drag(phone_id, from_x, from_y, to_x, to_y, hold_duration_ms?)` | Long press, then drag between two points |
| `double_tap(phone_id, x, y)` | Double tap at coordinates |
| `long_press(phone_id, x, y, duration?)` | Press and hold at coordinates |
| `lock(phone_id)` | Lock the phone |
| `unlock(phone_id)` | Unlock the phone |
| `get_phone_status(phone_id)` | Get connection and device status |

## How It Works

Claude follows a **screenshot → look → act → verify** loop:

1. `list_phones` — choose a phone and save its `phone_id`
2. `screenshot(phone_id)` — see the current screen
3. Visually identify UI elements and their coordinates
4. `tap(phone_id, 300, 672)` — interact at the identified position
5. `screenshot(phone_id)` — verify the action worked

All coordinates map 1:1 with screenshot pixels. Screenshots are scaled so the longest edge is 1344px, and the MCP handles native-to-scaled coordinate conversion transparently.

Ask Claude naturally:

- "Open Settings and turn on Dark Mode"

- "Open Safari and search for the weather"

## Notes

- **Phone discovery** — call `list_phones` first, choose a phone, and pass its `phone_id` to every other tool.
- **Multi-phone** — use the IDs from `list_phones` to target the correct phone on each call.
- **Text input** — focus a text field, then use `type_text` to enter text.
