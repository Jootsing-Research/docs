TapKit works natively with Claude through MCP (Model Context Protocol). Use the Claude app plugin in Chat and Cowork, or install the separate Claude Code plugin for terminal workflows.

## Claude app

Install the TapKit plugin in the Claude app to use it from Chat and Cowork. The plugin adds the TapKit connector and its phone-control tools.

<Card title="Set up the Claude app" icon="message" href="/integrations/claude-app">
  Install the plugin, connect TapKit, and grant tool permissions.
</Card>

### Example prompts

Try these to get started:

- "Open Settings and take a screenshot"
- "Go to Safari and search for flights to Denver"
- "Open DoorDash and order from the first restaurant"
- "Take a screenshot and tell me what apps are on the home screen"

## Claude Code

The TapKit plugin for Claude Code gives Claude iPhone control in your terminal. It installs an MCP server connection and TapKit skills that teach Claude how to use the tools and navigate supported apps.

<Card title="Set up Claude Code" icon="terminal" href="/integrations/claude-code">
  Install the current plugin, authenticate, and verify the connection.
</Card>

## Available actions

The same phone-control actions are available in Claude Chat, Cowork, and Claude Code:

| Action | Description |
|--------|-------------|
| `list_phones` | List available phones |
| `screenshot` | Capture the current phone screen |
| `tap` | Single tap at screen coordinates |
| `type_text` | Type text into the focused field |
| `press_home` | Go to home screen |
| `swipe` | Swipe up, down, left, or right |
| `drag` | Drag between two points |
| `hold_and_drag` | Long press, then drag between two points |
| `double_tap` | Double tap at screen coordinates |
| `long_press` | Press and hold at screen coordinates |
| `lock` | Lock the phone |
| `unlock` | Unlock the phone |
| `get_phone_status` | Get connection and device status |

<Note>
  `list_phones` does not require a phone ID. Call it first, then pass the returned `phone_id` to every tool that targets a specific phone.
</Note>

For connection details and tool signatures, see the [MCP guide](/integrations/mcp).

## Troubleshooting

<AccordionGroup>
  <Accordion title="Claude says TapKit isn't connected">
    Make sure the TapKit Mac app is running with a phone connected. In Claude Code, run `/mcp` to check the connection status. You may need to re-authenticate.
  </Accordion>

  <Accordion title="Actions are timing out">
    Check that your phone is awake, unlocked, and still connected. If the Mac app shows the phone as disconnected, unplug and reconnect the USB cable.
  </Accordion>

  <Accordion title="Phone not showing up in available devices">
    If you have multiple phones, Claude may need to select the right one. Ask Claude to "list my available phones" and then specify which one to use.
  </Accordion>

  <Accordion title="MCP server won't authenticate">
    Try clearing the cached auth token by running `/mcp` in Claude Code, selecting TapKit, and choosing to re-authenticate. Make sure you're signed into the correct TapKit account in your browser.
  </Accordion>
</AccordionGroup>
