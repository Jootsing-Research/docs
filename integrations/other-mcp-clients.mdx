Any tool that speaks MCP (Model Context Protocol) can connect to TapKit. This includes Cursor, Windsurf, custom agents, and any other MCP-compatible client.

## Setup

Add the TapKit MCP server to your client's configuration:

```json
{
  "mcpServers": {
    "tapkit": {
      "type": "http",
      "url": "https://mcp.tapkit.ai/mcp"
    }
  }
}
```

Where you add this depends on your client:

- **Cursor** — add to your MCP settings in the Cursor configuration
- **Windsurf** — add to the MCP configuration file
- **Custom clients** — point your MCP client at `https://mcp.tapkit.ai/mcp`

## Authentication

When your client first connects to the TapKit MCP server, you'll be prompted to authenticate via browser. Sign in with your TapKit account and the token will be cached for future sessions.

## Available tools

Call `list_phones` first to discover available phones. Every other tool requires a `phone_id` returned by `list_phones`.

Once connected, your client has access to these TapKit tools:

| Tool | Description |
|------|-------------|
| `list_phones` | List available phones |
| `screenshot(phone_id)` | Capture the current phone screen |
| `tap(phone_id, x, y)` | Single tap at coordinates |
| `type_text(phone_id, text)` | Type text into the focused field |
| `press_home(phone_id)` | Go to the home screen |
| `swipe(phone_id, x, y, direction)` | Swipe up, down, left, or right |
| `drag(phone_id, from_x, from_y, to_x, to_y)` | Drag between points |
| `hold_and_drag(phone_id, from_x, from_y, to_x, to_y, hold_duration_ms?)` | Long press then drag |
| `double_tap(phone_id, x, y)` | Double tap at coordinates |
| `long_press(phone_id, x, y, duration?)` | Press and hold at coordinates |
| `lock(phone_id)` | Lock the phone |
| `unlock(phone_id)` | Unlock the phone |
| `get_phone_status(phone_id)` | Get connection and device status |

## How it works

The MCP server runs as a hosted endpoint at `mcp.tapkit.ai`. You don't need to run anything locally beyond the [TapKit Mac app](/setup/mac-app) with a connected iPhone.

Your MCP client connects to the server, which routes commands to the Mac app, which executes them on the phone. Screenshots are returned through the same channel.

All coordinates map 1:1 with screenshot pixels. Screenshots are scaled so the longest edge is 1344px — the server handles coordinate conversion transparently.

## Tips

- **Phone discovery** — call `list_phones` first, choose a phone, and pass its `phone_id` to every other tool.
- **Multi-phone setups** — use the IDs from `list_phones` to target the correct phone on each call.
- **Text input** — focus a text field, then use `type_text` to enter text.
- **The agent loop** — the standard pattern is: `screenshot(phone_id)` → reason about what's on screen → perform action → `screenshot(phone_id)` again to verify.
