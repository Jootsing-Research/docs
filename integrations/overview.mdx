TapKit connects to the AI tools you already use. You can write code if you want, but it's not a requirement. TapKit has plugins for all of the major AI providers, and MCPs and skills for everyone else.

## What's the same everywhere

Every integration lets you inspect and operate the phone through screenshots, gestures, text input, and device controls. The platform changes how you talk to TapKit, not the phone workflow itself.

<Info>
  **All integrations require the TapKit Mac app running with at least one phone connected.** If you haven't set that up yet, start with [Mac App Setup](/setup/mac-app).
</Info>
