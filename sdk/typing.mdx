---
title: Typing
description: Type text into iOS apps
---

Use `phone.type_text()` to enter text into the currently focused field on the phone.

## Basic usage

```python
phone.type_text("Hello world")
```

## Focus a field first

Tap the text field before typing:

```python
phone.tap((300, 500))
phone.type_text("name@example.com")
```

The field must be visible and focused before you call `type_text()`.
