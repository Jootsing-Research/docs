---
title: Update Settings
description: Update a phone's display name
api: PATCH /v1/phones/{phone_id}/settings
---

Set or clear the custom display name for a phone.

## Request

```bash
curl -X PATCH https://api.tapkit.ai/v1/phones/{phone_id}/settings \
  -H "X-API-Key: joot_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"display_name": "QA iPhone"}'
```

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `phone_id` | `string` | The phone identifier |

### Request Body

```json
{
  "display_name": "QA iPhone"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `display_name` | `string \| null` | No | Custom display name, or `null` to clear it |

## Response

Returns the full phone object with updated settings. See [List Phones](/api-reference/phones/list-phones) for the complete response schema.

## Examples

### Clear the Display Name

```bash
curl -X PATCH https://api.tapkit.ai/v1/phones/{phone_id}/settings \
  -H "X-API-Key: joot_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"display_name": null}'
```

### Python

```python
import requests

response = requests.patch(
    "https://api.tapkit.ai/v1/phones/{phone_id}/settings",
    headers={
        "X-API-Key": "joot_...",
        "Content-Type": "application/json"
    },
    json={"display_name": "QA iPhone"}
)
phone = response.json()
print(f"Updated display name: {phone['display_name']}")
```

## Notes

- Set `display_name` to `null` to use the phone's default name.
- The display name appears in [List Phones](/api-reference/phones/list-phones).
